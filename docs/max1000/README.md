# MAX1000-FORTH manual (copy)

`MAX1000-FORTH-Manual.pdf` is a copy of [MAX1000-FORTH](https://github.com/andiepp/MAX1000-FORTH)'s
`docs/Manual.pdf` (release 1.0). The app embeds it: its **Manual** button (F1) opens this
manual when it is connected to a MAX1000 (or was, last time), the ZYNQ-FORTH manual
otherwise. Replace the copy when MAX1000-FORTH's manual changes.
